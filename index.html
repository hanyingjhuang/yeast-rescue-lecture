IVThree patient stories

Three mitochondrial diseases

LHON can damage the optic nerve. MELAS can disrupt brain function. Barth syndrome can weaken the heart.

Different genetic defects disrupt mitochondrial function. The tissue affected helps explain what each patient experiences.

VThe yeast model

A yeast model of mitochondrial dysfunction

This yeast mutant grows on glucose but poorly on glycerol. That difference lets us study a feature of mitochondrial disease in the lab: impaired respiration.

The yeast strain carries its own genetic defect. Can a second mutation improve growth when respiration is required?

VIThe candidates

A second change

A suppressor can improve growth while the original mutation remains.

An allele is a version of a gene. Compare each candidate with the unmutated version on the same plasmid backbone.

VIITransformation

One culture for each candidate

Introduce each plasmid into a separate culture of the same mutant. Select transformants on glucose medium using the plasmid marker.

Record each construct’s position on the master plate. That position will identify it after transfer.

VIIIThe controls

What counts as rescue?

Compare candidates with matched controls. Wild type checks that respiratory growth is possible. The mutant with empty vector defines baseline growth.

Test the reference allele in the same mutant with the same vector and promoter. Similar rescue by both alleles would be consistent with a gene dosage effect.

IXThe carbon source

When respiration matters

Yeast can ferment glucose. A colony can grow on glucose even when respiration is impaired.

With glycerol as the sole carbon source, growth requires mitochondrial respiration.

XReplica plating

Carry the pattern across

Press the inverted glucose master gently onto sterile velvet, then lift it. Align the fresh glycerol plate and touch its agar to the same velvet.

Each position on the replica now corresponds to a known construct on the master.

XIAfter incubation

Read the replica

Match each position across plates. A blank replica spot could reflect poor transfer or poor growth. A parallel glucose replica can check transfer.

In this example, B grows on glycerol. Compare B with the reference allele before attributing rescue to the mutation.

XIIBack to the patients

A clue worth testing in human cells

If a mutation repeatedly improves yeast growth, identify the process it changes. A conserved process gives researchers a candidate to test in human cells.

Choose a model relevant to the disease, such as patient-derived heart muscle cells for Barth syndrome. Test whether changing that process improves respiration and contraction.
